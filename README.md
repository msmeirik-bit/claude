# Dörrknack

Räknare för dörrknackning med karta. Öppna `index.html` via GitHub Pages på mobilen.

- **Knacka dörr** räknar varje dörr.
- **Offert / Inte intresserad / Öppnade inte** sätter en pin på kartan där du står (GPS). Dra pinen eller tryck på kartan för att flytta den.
- Vid **Offert** skriver du in ett namn på offerten. Alla offerter listas under **Offerter** och går att söka i.
- **Positiv / Negativ kund** registrerar kundbemötandet.
- Datan sparas i telefonens webbläsare. **Exportera CSV** laddar ner allt med koordinater.

## Publicera

Settings → Pages → Source: *Deploy from a branch* → välj grenen och `/ (root)` → Save.
Sidan hamnar på `https://msmeirik-bit.github.io/claude/`.
